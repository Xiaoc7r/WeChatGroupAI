# WeChatGroupAI

Windows 微信群 AI 助手，当前版本 **v4.1**，最多同时服务 **3 个群**。

- 群内 @ 问答，各群上下文独立，最多使用 500 条已采集消息。
- 每日早安与定时总结，默认以前一天 09:00 至当天 09:00 为范围，时间可调。
- 支持回答风格编辑、手动预览和发送、API 连接测试。
- 启动、停止不发群通知；页面顶部显示运行状态和异常暂停原因。
- 发送共用队列，至少间隔 20 秒；检测到登录异常或连续发送未确认时暂停。

命令：`/help`、`/all`、`/today`、`/status`、`/member @昵称`、`/morning`；`/eat` 暂时回复“尚未统计”。当前微信号可用 `/ai 问题` 测试。

## 使用

1. 准备 Windows x64、Python 3.12 x64（含 Python Launcher、Tkinter）和官方微信客户端。
2. 下载源码并解压，双击 `Install.cmd`，完成后打开桌面快捷方式或 `Start.cmd`。
3. 手动登录微信，填写自己的 API Key、可用模型、群名称和本微信号的群昵称。
4. 先用一个群预览，确认后再启用自动回复或添加其他群。

详情见 [使用指南](使用指南.md)。已有安装可使用 `UPDATE.cmd`；默认服务器目录见指南。
运行 `python tools/build_server.py` 可生成 `server/WeChatGroupAI-server.zip`。仓库提供源码和安装脚本，不含独立 EXE。

## 注意

`data/` 保存私密配置、Key 和聊天历史，不要上传或分享。API 调用可能收费，群聊处理需取得成员同意。
第三方接入依赖 Windows 桌面会话和微信版本兼容性，不能保证永久在线或避免账号限制。登录、安全验证需在官方微信中手动完成。

主要依赖：wechatauto-replica、Requests、pywin32。依赖通过安装脚本获取，不随仓库打包。项目暂未指定开源许可证。
